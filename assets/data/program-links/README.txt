PROGRAM AND MATERIAL URL WORKSHEETS

Fill in the URL after each colon.

Rules:
- Use one individual file or video URL per field, not a Google Drive folder URL.
- For Google Drive, set access to "Anyone with the link" and role to "Viewer".
- Test every URL in a private/incognito browser window before submitting it.
- If a View and Download button use the same Drive file, paste the same URL
  into both fields.
- Leave a field blank if that resource does not exist. The unused website
  button will be removed.
- Program thumbnails and documentation photos are already stored locally in
  assets/images/programs and do not need URLs.
